# Human Detection System using YOLO and PyTorch

## Overview
This project is a real-time Human Detection System developed using YOLO and PyTorch. The model detects humans in images and video streams with bounding-box visualization for accurate object detection.

## Features
- Real-time human detection
- Bounding box visualization
- Image and video stream processing
- Fast and efficient object detection
- Deep learning-based implementation

## Technologies Used
- Python
- PyTorch
- YOLO
- OpenCV

## Project Workflow
1. Data preprocessing
2. Model loading/training
3. Human detection
4. Bounding box generation
5. Output visualization

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/human-detection-yolo-pytorch.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python detect.py
```
